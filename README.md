# Quiet Orbit · 고요한 궤도

아무것도 하지 않아도 괜찮은 시간. 마우스를 따라 흐르는 별과 다섯 가지 우주를 바라보는 작은 휴식 공간입니다.

A peaceful space to unwind with responsive stars, twinkling light, and five slowly changing universes.

## Experience

- 마우스와 터치에 반응하는 별빛, 화면을 누르면 퍼지는 작은 별들
- 보라·청록·장미·황금·푸른빛의 다섯 우주와 부드러운 장면 전환
- 50초 동안 움직임이 없으면 다음 우주로 자동 항해
- 메뉴를 숨기는 몰입 모드, 선택형 우주 소리, 전체 화면과 일시정지
- 모바일 화면과 기기의 ‘동작 줄이기’ 설정 지원

## Visit

GitHub Pages: https://hoodie5622.github.io/Quiet-Orbit/

기기에서 동작 줄이기를 사용하는 경우, 화면 아래 **움직임 켜기**로 자동 항해를 시작할 수 있습니다. 소리는 오른쪽 위 스피커 버튼으로 켭니다.

## Controls

- **Space**: 움직임 멈추기 / 이어가기
- **← / →**: 이전 / 다음 우주
- **M**: 소리 켜기 / 끄기
- **F**: 전체 화면
- **H**: 메뉴 숨기기 / 다시 보기
- **Esc**: 몰입 모드에서 돌아오기

## Run locally

설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다. HTML, CSS, Canvas 2D, Web Audio로 만들었습니다. 별도 이미지·오디오 파일이나 런타임 패키지가 필요하지 않습니다.

웹 글꼴은 Google Fonts를 사용하며 연결되지 않으면 기기의 기본 글꼴로 표시합니다.

## Deploy

GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch → main → / (root)**를 선택합니다. 이 저장소의 파일들이 그대로 정적 사이트가 됩니다.
