# Quiet Orbit · 고요한 궤도

아무것도 하지 않아도 괜찮은 시간. 마우스를 따라 흐르는 별과 여덟 가지 우주를 바라보는 작은 휴식 공간입니다.

A peaceful space to unwind with responsive stars, eight slowly changing universes, constellations, and original ambient sound.

## Experience

- 마우스와 터치에 반응하는 별빛, 화면을 누르면 퍼지는 작은 별들
- 성운, 오로라, 장밋빛 먼지, 일식, 나선 은하, 고리 행성, 얼음빛 심연, 쌍성의 여덟 우주
- 우주마다 다른 대표 별자리와 배경음, 부드러운 화면·소리 전환
- 별빛을 따라 연결선이 차례로 그려지는 별자리 연출. 선택한 우주를 다시 누르면 재생
- 마우스 움직임과 관계없이 약 32초마다 다른 우주로 무작위 자동 항해
- 별자리와 행성이 같은 우주의 흐름을 따라 부드럽게 이동
- 모든 메뉴를 숨기는 몰입 모드, 0–100% 음량 조절, 전체 화면과 일시정지
- 모바일 화면과 기기의 ‘동작 줄이기’ 설정 지원

## Visit

GitHub Pages: https://hoodie5622.github.io/Quiet-Orbit/

기기의 동작 줄이기 설정을 따르며, 이 경우에도 우주는 자동으로 바뀝니다. 화면 아래 **움직임 켜기**를 누르면 별자리 연결 연출과 우주의 움직임도 볼 수 있습니다. 소리는 오른쪽 위 스피커 버튼으로 켜고 슬라이더로 조절합니다. 음량은 다음 방문에도 기억하며 소리는 자동 재생하지 않습니다.

## Universes

| 우주 | 대표 별자리 | 배경음 |
| --- | --- | --- |
| 별빛의 바다 | 오리온자리 | 성운의 잔향 |
| 푸른 숨결 | 백조자리 | 오로라의 바람 |
| 장밋빛 꿈 | 거문고자리 | 장밋빛 숨결 |
| 황금빛 고요 | 사자자리 | 일식의 울림 |
| 아득한 은하 | 안드로메다자리 | 은하의 자장가 |
| 고리의 정원 | 카시오페이아자리 | 고리의 여운 |
| 얼음빛 심연 | 작은곰자리 | 얼음별의 속삭임 |
| 쌍성의 새벽 | 쌍둥이자리 | 두 태양의 화음 |

별자리는 실제 형태를 바탕으로 감상용으로 배치했습니다. 관측용 천체 지도는 아닙니다.

## Controls

- **Space**: 움직임 멈추기 / 이어가기
- **← / →**: 이전 / 다음 우주
- **M**: 소리 켜기 / 끄기
- **F**: 전체 화면
- **H**: 메뉴 숨기기 / 다시 보기
- **Esc**: 몰입 모드에서 돌아오기
- **모바일 두 번 탭**: 몰입 모드에서 돌아오기

## Run locally

설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다. HTML, CSS, Canvas 2D, Web Audio로 만들었습니다. 별도 이미지·오디오 파일이나 런타임 패키지가 필요하지 않습니다.

웹 글꼴은 Google Fonts를 사용하며 연결되지 않으면 기기의 기본 글꼴로 표시합니다.

## Deploy

GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch → main → / (root)**를 선택합니다. 이 저장소의 파일들이 그대로 정적 사이트가 됩니다.
